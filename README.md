### React Redux Todo

Приложение для управления списком задач, разработанное на React и TypeScript.

**Функциональность:**
- Добавление, удаление и отметка задач как выполненных.
- Управление состоянием через Redux Toolkit.
- Сохранение списка задач в LocalStorage.
- Валидация ввода.

**Технологии:** React, TypeScript, Redux Toolkit, React Redux, RTK Query, Vite.
